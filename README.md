## Installation & Download

The installation media is available directly in the **GitHub Releases** section. Due to file size limits, the ISO is split into 3 parts.

### How to get the ISO:
1. Go to **Releases** on the right side of this repository and download all `part-` files.
2. Open your terminal and run the following command to combine them:

```bash
cat octopus-1.0.0.iso.part-* > octopus-1.0.0-2026.05.31-desktop-amd64.iso
```
